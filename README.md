# Adımım

Telefonun hareket sensörünü kullanarak günlük adım sayısını gösteren Flutter
uygulaması. Uygulama günlük hedef, hedef ilerlemesi, yaklaşık mesafe ve kalori
bilgilerini sunar.

## Çalıştırma

```sh
flutter pub get
flutter run
```

Adım sensörü emülatörlerde genellikle bulunmadığı için uygulamayı fiziksel bir
Android veya iOS cihazda test edin. Android'de ilk açılışta fiziksel aktivite
iznini kabul edin.

A new Flutter project.
